The Cargo API provides programmatic access to protocol data, including vault statistics, asset prices, and historical yield. It is intended for dashboards, aggregators, and programmatic deposit workflows.

## Base URL

```text
https://api.example.com
```

Replace the base URL with the production endpoint once it is live.

## Endpoints

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/vaults` | List all vaults with basic metadata. |
| GET | `/v1/vaults/{vaultId}` | Fetch detailed data for a specific vault. |
| GET | `/v1/vaults/{vaultId}/yield` | Retrieve current and historical yield for a vault. |
| GET | `/v1/assets` | List supported real-world assets. |
