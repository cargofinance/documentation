Strategy contracts implement the actual investment logic for Cargo vaults. Each vault can route funds into one or more strategies that target specific real-world asset pools or instruments.

## Core Responsibilities

- Allocation: receive capital from the vault and deploy it into target positions.
- Harvesting: claim rewards or interest from the underlying instrument.
- Reporting: return the current total value of deployed assets to the vault on demand.

## Key Functions

| Function | Visibility | Description |
| --- | --- | --- |
| `invest(uint256 amount)` | `external` | Deploy `amount` of underlying assets into the target position. |
| `divest(uint256 amount)` | `external` | Withdraw up to `amount` from the position and return it to the vault. |
| `harvest()` | `external` | Claim available yield and either compound or forward it. |
| `estimatedTotalAssets()` | `view` | Return the current value of assets held in the strategy. |
