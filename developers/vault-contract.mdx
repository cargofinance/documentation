cvCOCOA is a permissioned **ERC-3643** token. It behaves like an ERC-20 for balances and approvals, but every transfer is checked against an on-chain identity registry.

## Token facts

| Property | Value |
| :-- | :-- |
| Standard | ERC-3643 (T-REX), ERC-20 compatible interface |
| Name / symbol | Cargo Vault Cocoa · Douala / cvCOCOA |
| Unit | 1 share = 1 kg of receipted cocoa |
| Settlement asset | USDC |
| Chain | Arc (fallback Base) |
| Holders | Whitelisted identities only |

<Note>
  cvCOCOA is **not** an ERC-4626 vault. There is no `deposit()` that mints shares against USDC. New shares are minted only against collateral-manager receipts and sold by the Vault SPV through the auction contracts.
</Note>

## What integrators need to know

- **Transfers can fail.** `transfer` and `transferFrom` revert if the receiver is not a verified identity, or if a compliance rule blocks the transfer. Check eligibility before routing a transfer.
- **The backing rule.** Total supply never exceeds receipted kilograms in the bay. Minting is guarded on-chain and requires a current collateral-manager receipt.
- **Pricing.** Value positions at NAV from the NAV feed, not from a pool price. For lending, use the lower of ONCC NAV and ICE-implied NAV.
- **Pauses.** The token and auctions can be paused by the pause guardian. Treat a paused state as "no transfers, no mints".

## Standard ERC-3643 interface (excerpt)

```solidity
interface ICvCocoa {
    // ERC-20
    function balanceOf(address account) external view returns (uint256);
    function totalSupply() external view returns (uint256);
    function transfer(address to, uint256 amount) external returns (bool);

    // ERC-3643
    function identityRegistry() external view returns (address);
    function compliance() external view returns (address);
    function paused() external view returns (bool);
    function isFrozen(address account) external view returns (bool);
}

interface IIdentityRegistry {
    function isVerified(address wallet) external view returns (bool);
}
```

## Events to index

| Event | Meaning |
| :-- | :-- |
| `Transfer` | Mint, burn or transfer of shares |
| `Paused` / `Unpaused` | Token paused or resumed |
| `AddressFrozen` | A wallet frozen pending review |
| `IdentityRegistered` (registry) | A wallet whitelisted |

The exact ABI, decimals and addresses are published with the deployment on [Contract Addresses](/resources/contract-addresses) and in [Code Repositories](/resources/code-repositories).
