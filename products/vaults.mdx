A Cargo vault holds one real-world asset in one location as receipted, pledged inventory, and issues one token against it. Each vault has its own lots and its own NAV. Cocoa, coffee, sugar, gold or any other asset that passes the [eight collateral tests](/products/real-world-assets#eight-tests-for-any-commodity) gets its own vault. The first programme, **Cargo Vault One**, opens with the **Genesis Vault**: Cameroon cocoa in Douala, issued as cvCOCOA.

## Every vault token

| | |
| :-- | :-- |
| Name | "cv" plus the asset, and the location code where needed (for example cvCOCOA, Cargo Vault Cocoa · Douala) |
| Unit | 1 share = 1 unit of the receipted asset (a kilogram, a tonne or an ounce) |
| Owner of the goods | A bankruptcy-remote Seychelles Vault SPV |
| Standard | ERC-3643 (permissioned): transfers only between whitelisted identities |
| Settlement asset | USDC |
| Custody | Holders' own wallets; administration through a Safe multisig with a timelock |
| NAV | The asset's published reference price, less levies and delivery costs, struck daily |
| Holder fees | No management or storage fee |

## The Genesis Vault: cvCOCOA at a glance

| | |
| :-- | :-- |
| Name | Cargo Vault Cocoa · Douala (cvCOCOA-DLA) |
| Unit | 1 share = 1 kg of receipted cocoa |
| Asset | Export-grade Cameroon cocoa beans, fermented, dried and bagged |
| Location | Collateral-managed bay at AGL Bonabéri, Douala |
| NAV | ONCC FOB reference − export levy − FOB costs, struck daily; $5.277 at 9 Oct 2026 |
| Hedge equivalence | 10,000 shares move like one ICE London cocoa lot (10 t) |
| Batch auctions | Every 12 days, after Genesis settlement |

A new asset or a new location is a new vault with its own lots and NAV. Port vaults are named by their UN/LOCODE. Every new line must pass the same [eight collateral tests](/products/real-world-assets#eight-tests-for-any-commodity).

## Before you bid

<Check>Complete KYC or KYB and whitelist your wallet. See the [Quickstart](/quickstart).</Check>
<Check>Verify the contract address on the [Contract Addresses](/resources/contract-addresses) page and the deposit address by phone, never from a message.</Check>
<Check>Read the [Risk Checklist](/safety/risk-checklist) and the Risk Statement in the data room.</Check>
<Check>Check today's NAV, the lots listed for the batch and their reserves.</Check>

<Note>
  Vault shares are for eligible non-US professional or institutional investors outside Seychelles and any jurisdiction the vault's term sheet excludes (CEMAC for the Genesis Vault). Parameters can change with 30 days' notice; your signed agreement and the Rulebook are binding.
</Note>
