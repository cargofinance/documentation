A cvCOCOA share is only as safe as the weakest link between the bean and the wallet. Cargo secures each link separately.

## The security stack

| Layer | Control |
| :-- | :-- |
| Goods | Independent collateral manager with sole release authority; goods leave only against payment |
| Verification | Vallis weighs and grades every lot; discrepancies above 0.5% suspend the lot |
| Title | Bankruptcy-remote Vault SPV owns every lot |
| Security | One OHADA pledge with dispossession, registered at the RCCM, held by a security agent |
| Loss absorption | 10% subordinated first loss per lot; all-risks insurance |
| Token | ERC-3643: transfers only between whitelisted identities; a liquidation can never leave the permissioned perimeter |
| Minting | Shares minted only against a collateral-manager receipt; supply cannot exceed receipted kilograms |
| Administration | Safe multisig with a timelock and an independent co-signer; pause guardian |
| Price | Daily NAV with ICE cross-check, fallback and lower-of oracle for lending |

## Code review and testing

Contracts that mint, auction and hold value will be independently audited before mainnet; no audit has been completed yet. Reports will be published on [Audits & Bug Bounty](/safety/audits-and-bug-bounty).

## Access controls

- Privileged functions (minting, pausing, parameter changes, identity registry updates) are restricted to named roles.
- The identity registry signer key is held under the Safe policy.
- Parameter and rule changes follow 30 days' notice; only safety pauses are immediate.

## Operational security and AML

- KYC and KYB through Persona, with sanctions, PEP and adverse-media screening.
- Wallet screening on registration, on every new order and every six months; wallets exposed to sanctioned addresses are frozen pending review.
- Source of funds checked above $100,000.
- Identity data stays with the verification provider and the compliance team. Only a participant ID and wallet status go on-chain.
- Deposit addresses are confirmed by phone with a named director and a test transfer, never by message.

## Incident response

<Steps>
  <Step title="Detect">
    Automatic triggers: NAV oracle failure, a collateral-manager discrepancy above 0.5%, a sanctions hit or a chain incident.
  </Step>
  <Step title="Contain">
    The affected batch, creations or redemptions are suspended. A suspect lot is frozen until topped up or met from subordinated shares, with an independent recount.
  </Step>
  <Step title="Communicate">
    The reason is published on the official channels and sent to eligible investors.
  </Step>
</Steps>

<Warning>
  Paper records (receipts, the pledge register and signed agreements) are the fallback if a chain or key fails. No set of controls removes all risk.
</Warning>
